# Live Forever

**Tagline:** Unki yaadein, unka ehsaas — hamesha aapke saath.

Live Forever is a digital memory and connection platform concept for preserving photos, videos, voice recordings, stories and meaningful moments of loved ones.

## Current MVP
This repository contains the first frontend foundation:
- Live Forever landing page
- Memory space concept
- Memories / stories / connection sections
- Future chat, voice and video presence placeholders
- Privacy and AI-disclosure positioning

## Run locally

Install Node.js (LTS), then:

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Roadmap
1. Authentication
2. Create a Loved One / Memory Space
3. Secure media uploads
4. Database and memory timeline
5. AI memory retrieval and chat
6. Consent and family sharing
7. Voice experience
8. Video/avatar experience

AI experiences should be clearly presented as digital representations, not as the literal person.
